# Minimalist Wallpaper

collection of clean, modern, and minimalist wallpapers for desktop.

## About

Minimalist Wallpaper is a simple website for browsing and downloading
minimalist wallpapers.

The project is built as a learning project while exploring modern web
development with Astro and Tailwind CSS.

## Tech Stack

- Astro
- Tailwind CSS
- JavaScript
- HTML
- CSS

## Features

- Clean and minimal interface
- Browse minimalist wallpapers
- Download wallpapers in full resolution
- Responsive design
